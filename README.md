# 폴디 Foldy — 접어서 외우는 가족 영어 단어장

**라이브: https://foldy-lake.vercel.app** (GitHub main에 올리면 Vercel이 자동 배포)

초등 1학년부터 성인까지, 가족이 한 아이디로 함께 쓰는 영어 단어장 웹앱입니다.
교재 사진을 찍으면 단어가 한꺼번에 들어가고, 수첩처럼 **정답을 가림판으로 가린 세로 목록**에서 여러 단어를 한 번에 외웁니다.
모바일 브라우저에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 기능

**1차**
- 처음 접속하면 소개 슬라이드 8장(아이콘 3개가 하나씩 튀어나오며 주요 기능 소개, 다음·이전·밀기) → 마지막 장 '폴디 시작하기'로 앱 진입. 기기마다 한 번만(localStorage `foldy.introSeen`), 내 정보 '폴디 소개 다시 보기'로 다시 열기
- 가족 아이디+비밀번호 로그인 → 구성원(프로필) 선택. 이메일·전화번호는 받지 않음
- 구성원별 숫자 비밀번호(4~6자리, 선택): 걸면 다른 가족은 내 단어장을 못 고치고 **학습현황만** 볼 수 있음(DB 보안정책으로 강제). 프로필을 바꾸면 다시 잠김
- 상단 프로필 아이콘 → 이름(닉네임, 한 달에 한 번만 — 서버 트리거로도 막음)·캐릭터·레벨·비밀번호 수정, 가족 학습현황(○△✕ 막대·연속일·오늘 정답)
- 단어 추가
  - 📷 사진: 여러 장 한 번에, JPG·PNG·WEBP·아이폰 HEIC(확장자가 틀린 HEIC 포함) 모두 → 긴 변 2000px로 줄여 AI가 읽음 → 미리보기에서 고친 뒤 저장. 기다리는 동안 캐릭터 대기화면(진행률·팁·톡 누르면 점프)
  - AI를 못 쓰면(키·크레딧·서버 오류) 기기 안 무료 글자인식(Tesseract, 영어+한국어)으로 자동 대체. 빈 파일·iCloud 미다운로드 등 못 읽은 사진은 이유와 함께 표시
  - ✍️ 직접 적기: 영어나 한글 몇 글자만 쳐도 사전 9,121단어에서 바로 찾아 탭하면 담김(사전에 없으면 AI가 자동으로 찾아 'AI' 표시로 보여주고 결과는 공유 캐시에 저장) + 여러 개 한 번에 적기(`apple 사과`, 뜻이 비면 사전으로 채움)
- 접이식 단어장: 뜻 가리기·영어 가리기·모두 보기, 가림판 탭하면 열림, 영어 탭하면 발음 재생
- 단어장 한 칸: 번호·영어 철자·🔊·'탭해서 보기' 가림판, 아래에 3단계 학습 아이콘(뜻·철자·발음 — 통과한 것은 주황·초록·코랄 색 + ✓)과 추가 날짜
- 번호/날짜/ABC 정렬(↑↓), 미학습 / △ 학습 중 / ○ 완료 필터, 상단 '○를 기다리는 단어 N개 → 지금 끝내기'
- 단어 바로 뒤 🔊 발음 듣기, ⋯ 메뉴 → ✏️ 고치기 / 🗑 삭제(확인 후 삭제)
- ☑ 선택: 이미 아는 단어를 체크해 한꺼번에 지우기(보이는 단어 모두·○ 완료만 고르기, 두 번 눌러 확인)
- 줄바꿈: 한글은 띄어쓰기에서만 줄이 바뀌고(단어 중간 안 자름), 영어 단어는 칸에 맞을 때까지 글자를 줄여 한 줄로(FitWord), '…' 말줄임 없음
- 저장 안전: 답을 저장하는 중에 앱을 닫거나 새로고침해도 줄 서 있던 저장을 바로 보내고(keepalive) 끝까지 감
- 퀴즈 첫 문제부터 발음 자동 재생(영어→뜻·발음 퀴즈), 아이폰 소리 제한은 첫 터치 때 잠금 해제
- 퀴즈 3종(10문제씩, 못 맞힌 단어 먼저)
  - **오늘의 단어**: 하루 목표 개수만큼 단어를 그날 아침 고정(학습 중 → 미학습, 번호 순). 퀴즈 3종·○ 만들기 도전은 이 단어들만 출제 — 못 맞힌 것부터, 다 맞히면 같은 단어로 '다시 외우기'(n바퀴째 표시, 연습 바퀴에서 틀려도 맞힌 기록은 유지). 원하면 '새 단어 N개 더 하기'로 오늘의 단어를 늘림(DB `foldy_daily.set_ids`)
- **오늘 복습**: 복습 날이 된 ○ 단어 + 오늘 한 번이라도 푼 단어가 자동으로 들어감(`foldy_daily.seen_ids`)
  - 영어 → 뜻: 어미·띄어쓰기·여러 뜻 중 하나·오타 1자 허용 + AI 허용답안 + "내 답도 맞아요"(AI 재채점)
  - 뜻 → 영어: 철자 정확히(대소문자·관사 무시)
  - 틀리면 '내가 쓴 답'을 함께 보여 줌 — 철자 퀴즈에서 거의 맞힌 답은 틀린 글자(빨간 밑줄)·빠진 글자(_) 자리를 표시. '모르겠어요'는 표시 안 함
  - 발음: 음성 인식 결과를 철자·소리 유사도로 비교해 **정석 발음 대비 70% 이상이면 통과**(정확도 % 표시, r/l·v/f 혼동 허용). '🎧 더 정확한 발음 들어보기' → 보통/천천히 듣기, 발음기호, 강세 음절, 한글 흉내, 입 모양 요령, 내 발음 조언
  - 마이크 선택: 기기 마이크 목록·소리 크기 테스트(내 정보, 발음 퀴즈 안). 크롬 최신판은 고른 마이크로 인식, 그 외는 기기 기본 마이크
- 틀리거나 ‘모르겠어요’ 하면 오답노트에 바로 담기고, 그 방식으로 다시 맞히면 빠짐(오답노트 = 지금 모르는 단어만) → 오답노트 '다시 익히기' 3단계: ① 다시 보기(단어·발음기호·뜻·예문) ② 쉬운 문제(뜻 4지선다) ③ 원래 틀린 방식으로 다시 풀기
  - 서로 다른 날 3번 맞히면 졸업(맞힐 때마다 3일 뒤 → 7일 뒤에 다시 만남, 틀리면 처음부터). 일반 퀴즈에서 한 번 맞혀도 빠지지 않음
  - 다시 볼 날이 된 단어는 하루 3개씩 오늘의 학습에 끼워 넣음(홈 목표 줄·학습 화면 줄·아래 탭 배지). 졸업하면 캐릭터가 2번 더 먹음
- **○ 판정: 세 가지 퀴즈를 모두 맞혀야 ○**
- 학습 화면: 모두 맞힌 퀴즈는 초록 ✓, 진행 막대 / 🎯 ○ 만들기 도전(✕·△ 단어의 못 맞힌 퀴즈만 모아서)
- 효과음(타자·정답 차임·오답·팡파르, 끄기 가능)과 정답·오답 캐릭터 애니메이션·색종이
- 🛠 앱 수정요청(내 정보): 유형(버그·화면·불편·기능·기타)·화면 칩 + 내용(2,000자) → 우리 가족이 보낸 요청 목록에서 상태(접수됨·고치는 중·의견 보류·고쳤어요)와 답장 확인, 새 답장은 '새 소식'으로 표시. 멘토링대학교 수정요청 구조를 그대로 가져옴
- 수정요청함(`/#/admin`, 관리자 가족만): 상태 필터·신규 배지, 확인→수정진행·의견보류·수정완료, 빠른 답장·답장 고치기, 삭제. 관리자 가족은 DB `foldy_admins`(현재 bang9family)

- 🔑 비밀번호 찾기: 가족을 만들면 복구 코드(XXXX-XXXX-XXXX)를 한 번 보여 줌 → 로그인 화면 '비밀번호를 잊었어요'에서 가족 아이디+복구 코드로 새 비밀번호. 내 정보 › 가족 계정에서 비밀번호 바꾸기·복구 코드 새로 받기
- 구성원 숫자 비밀번호를 잊으면 비밀번호 입력판의 '비밀번호를 잊었어요' → 가족 비밀번호로 없애고 들어감
- 가족 계정 탈퇴(내 정보 › 가족 계정, 가족 비밀번호+확인 체크 → 모든 기록 즉시 삭제) · 개인정보 처리방침(표준 13개 조항, 가입 시 [필수] 동의)
- 🔔 알림(내 정보 › 알림): 마지막 학습 24시간 뒤 '오늘도 짧게 영어단어 하나 배워볼까요?'(오전 8시~밤 9시), 관리자 가족은 새 수정요청 알림. 아이폰은 홈 화면에 추가한 폴디에서만 받을 수 있음
- 가족 초대하기(내 정보): 링크와 '카톡이면 다른 브라우저로·아이폰 사파리/안드로이드 크롬으로 열기·홈 화면에 추가' 안내가 든 글을 보내거나 복사. 카톡 등 앱 안 브라우저로 열리면 아래에 '사파리/크롬으로 열기' 안내가 뜸
- 🎤 발음은 어디서나: 자동 채점(음성 인식 70%)이 되는 곳(아이폰 사파리·크롬)은 자동 채점, 안 되는 곳(아이폰 홈 화면 앱·카톡·마이크가 바뀐 데스크톱)이나 인식 오류·2번 실패 시엔 **내 목소리로 확인**(정답 듣기 → 3초 녹음 → 내 목소리와 번갈아 듣기 → '비슷해요'), 녹음도 안 되면 '따라 말했어요'. 고른 마이크가 빠지면 기본 마이크로. 자동 채점은 '사파리에서 열기' 링크로 이어받기 가능
- 📴 오프라인: 서비스워커가 화면·코드·발음 파일·글꼴을 저장, 마지막으로 받은 구성원·단어·오늘 기록을 기기에 보관 → 인터넷 없이도 열고 공부, 푼 답은 연결되면 자동 저장

**2차**
- 레벨 Lv.01~Lv.10 + 레벨 진단(레벨별 5단어 중 4개 이상 알면 다음 단계)
  - 기준: 2022 개정 영어과 교육과정 [별표 3] 기본 어휘 3,000개를 자주 쓰는 순서로 Lv.01~09(초등 권장 800 → Lv.01~03, 중·고 공통 1,200 → Lv.04~06, 나머지 → Lv.07~09), Lv.10은 그 밖의 실전 단어. 예전 값(e1·m 등)도 그대로 읽음
- 레벨업 게이지(홈 프로필 밑): 퀴즈 하나 통과 = 1 XP(지금 레벨보다 쉬운 단어는 제외), 다음 레벨까지 ○ 단어 30개(Lv.01~03)·40개. 다 차면 '레벨업!' 버튼
- 단어장 발음기호(IPA): ipa-dict(MIT) 9,081단어 내장, 없는 단어는 AI로 한 번 받아 기기에 저장
- 단어장 ➜ 버튼: 그 단어를 오늘 학습할 단어에 더함
- 오늘의 추천 단어(홈, '🔄 새로고침'으로 지금 보이는 단어를 빼고 다시 고름): 처음엔 레벨 목록에서 날짜별로 고정 선택, 내 단어가 20개 이상이면 내 단어와 같은 주제의 단어(AI 없이)
- 확장 학습: ○ 단어 → 유의어·반의어 퀴즈(영어·한글·발음 듣기/연습) → 둘 다 맞히면 예문(영어+한글+문장 읽기+장면 이모지)이 단어장에 열림
- 복습: ○ 단어를 1·3·7·30·60일 뒤 재출제, 틀리면 △로 내려감
- 😱 갉아먹기 장면: 이틀 이상 쉬었거나 학습 알림으로 들어오면 하루 한 번, 캐릭터들이 단어 3개를 갉아먹는 연출 → '복습하고 되찾기'. 단어장 내용은 바뀌지 않음
- 연속 학습일(🔥, 하루라도 빠지면 0으로 표시), 하루 목표 기본 5개(홈 '✎ 목표 바꾸기'·내 정보에서 1~50개로 조절) — 목표 수만큼 오늘의 추천 단어가 나옴

## 오늘 학습할 단어 직접 고르기
- 학습 화면 '📒 단어장에서 직접 고르기' 또는 단어장 '☑ 선택' → 공부할 단어를 골라 '📚 고른 N개로 오늘 학습하기'(최대 30개)
- 하루 목표 개수만큼은 골라야 학습 버튼이 열림(단어장이 목표보다 작으면 있는 만큼) · 목표보다 많이 고르면 그만큼 오늘의 단어가 늘어남(`chooseSet` → extra)
- 고른 단어만 오늘의 단어가 되고 무작위 단어는 섞이지 않음 · 저장이 끝난 뒤 학습 화면으로 넘어감
- 오늘 기록 저장은 보낼 때의 최신 기록을 보냄(밀린 저장이 한꺼번에 나가도 옛 기록이 덮지 않게)
- 다음 날은 다시 자동으로 골라 줌(그날도 직접 고를 수 있음)

## 우리 가족 펫 (`/#/pet`)
- 가족이 한 마리를 함께 키움: 강아지·고양이·새·돼지·토끼·햄스터(지금 캐릭터와 같은 동글동글한 그림체, `src/components/PetArt.jsx`)
- 상태 3칸(배부름·신남·깨끗함, 0~100): 하루마다 20씩 줄고, 아프거나 죽지 않음(오래 못 돌보면 졸려 할 뿐)
- 돌봄권은 공부해야 생김(구성원별·하루): 🍖 밥 = 문제 10개 맞힐 때마다 1개(최대 3) · 🦮 산책 = 오늘의 한 판 끝내기 · 🛁 목욕 = 복습 3문제 또는 이틀 연속 공부
- 돌보면 그 칸 +35, 자람 +5 → 아기·꼬마(50)·어린이(200)·청소년(500)·어른(1200, 왕관)
- 오늘 누가 돌봤는지·이번 주 가장 많이 돌본 가족 표시, 홈에 펫 기분과 돌봄권 수
- 서버가 돌봄권을 다시 계산해서 화면을 건너뛰어도 못 씀(`foldy_pet_care` → NO_TICKET)
- DB: `foldy_family_pet`(가족당 1마리), `foldy_pet_log`(돌봄 기록) · 함수 `foldy_pet_get/adopt/rename/care` · 지금은 모두 무료(꾸미기·두 번째 펫은 유료 후보)

## 베타 사용 분석 (관리자 › 분석)

## ○ 기준·연습·하루 상한·쉼표 (2026-10-20)
- ○ = 뜻 + 철자. 발음은 ○를 막지 않고 🎤 발음 배지로 따로 모음(학습 화면에 개수 표시). 기존 단어 중 뜻·철자를 맞힌 단어는 ○로 바뀌며 복습 일정이 시작됨
- 연습하기(학습 화면): 🎧 듣고 쓰기(소리만 듣고 철자) · 🧩 빈칸 채우기(내장 예문 속 빈칸, 2,898개 중 2,888개 가능). ○·복습 기록은 바꾸지 않고 맞힌 수·연속 학습일에만 들어감
- 하루 상한: 맞힌 수가 하루 목표의 3배(`ENOUGH_X`)가 되면 '오늘은 충분해요' 안내, 새 단어 더 하기도 목표의 3배까지만
- 쉼표: 7일에 한 번, 하루를 통째로 쉬어도 연속 학습일 유지(`foldy_members.rest_day`). 홈 연속일 배지에 '쉼표 · 오늘 하면 N일째' 표시

## 오늘의 단어·연속 학습일
- 오늘의 단어 수는 하루 목표로 고정(‘새 단어 더 하기’를 누른 만큼만 늘어남, `foldy_daily.extra`). 단어장에서 ➜로 보낸 단어는 맨 앞에 들어가고, 아직 안 푼 단어 하나가 다음으로 밀려 개수는 그대로
- 날이 바뀌면 오늘의 단어를 새로 고름(○가 아닌 단어 중 학습 중 → 미학습, 번호 순). **전날(공부한 가장 최근 날) 다 못 끝낸 단어는 하루 뒤로 미루고 다음 단어부터 — 발음까지 못 끝냈어도 새 날엔 새 단어**(다른 단어가 모자라면 전날 단어로 채움, 그다음 날엔 다시 앞으로). 앱을 켜 둔 채 자정이 지나도 30초 안에 새 날짜로 다시 그림
- 연속 학습일은 그날 첫 정답을 맞히는 순간 +1(자정이 지났다고 저절로 늘지 않음). 홈 오른쪽 위에 ‘🔥 N일 연속’과 ‘오늘 하면 N+1일째 / 오늘 학습 완료’

**3차(차별화)**
- 🎯 가족끼리 단어 내기(가족 학습현황): 내 단어장에서 10개까지 골라 가족에게 보냄 → 받은 사람 홈에 카드·알림 → 뜻 맞히기 → 결과가 낸 사람에게 알림. 틀린 단어는 내 단어장에 담기
- 🏆 이번 주 가족 순위: 월요일부터 하루 목표를 채운 비율(%)로 비교 — 레벨·목표가 달라도 공평
- 📅 시험 대비(학습 › 시험 만들기): 이름·날짜·범위(넣은 날짜별로 묶어 고르기) → 남은 날(오늘 포함)로 나눈 오늘 분량, 홈 D-day 카드, 철자 모의고사(뜻 보고 영어 쓰기, 최대 40문제, 단어장 기록은 안 바뀜). 준비 끝 = 한→영·영→한 모두 맞힘
- ✨ 나만의 예문(내 정보): 켜고 별명·좋아하는 것(3개까지)을 적으면 새 단어 예문에 내가 주인공으로 나옴, '최근 10개 다시 만들기'. 별명·좋아하는 것만 AI에 보내고 공용 캐시에는 넣지 않음
- 🐣 캐릭터 키우기(홈): 퀴즈를 하나 통과할 때마다 캐릭터가 단어를 먹고 자람(아기 → 꼬마 15 → 어린이 45 → 청소년 90 → 어른 180 → 전설 300). 단계마다 리본·안경·모자·목도리·왕관이 생기고 켜고 끌 수 있음 — 가족 화면에도 그대로 보임

## AI 사용 범위 (유료 AI 없음)
- 유료 AI(Claude)는 쓰지 않아요. 코드에서도 지웠어요.
- **기본 어휘 2,898개(Lv.01~09)는 앱에 넣어 둔 데이터**(`src/data/vocab.json`)로 처리 — 허용 답안·유의어·반의어·예문(영·한·장면)·한글 발음 흉내·음절 강세·발음 요령. AI 호출 0회, 즉시(한 번 받은 뒤엔 오프라인에서도). 데이터는 개발 때 한 번 만들고 `scripts/gen/check.mjs`로 형식 검사

- 그 밖의 단어(교재에만 있는 단어·구), 사진 읽기, 뜻 재채점, 나만의 예문, 사전에 없는 단어 검색, 발음기호만 무료 AI(Gemini) — 결과는 `foldy_cache`에 저장해 같은 단어는 다시 묻지 않음. 가족당 하루 글 200회·사진 15장(`FOLDY_FREE_TEXT`·`FOLDY_FREE_VISION`)
- 사진 읽기가 안 되면(한도·붐빔) 기기 안 글자 인식(Tesseract)으로 대신

※ 맥에서 돌리는 FreeLLMAPI(`localhost:3001`)는 Vercel 서버가 접근할 수 없습니다. 인터넷에서 닿는 주소(배포한 FreeLLMAPI, OpenRouter·Groq 등 무료 키)를 넣어야 합니다.

Supabase 주소·공개 키는 코드에 기본값이 들어 있습니다(공개용 키, RLS로 보호).

## 로컬 실행

```bash
npm install
npm run dev          # 화면만 (AI 경로 /api 는 동작 안 함)
npx vercel dev       # AI 경로까지 (Vercel CLI 로그인 + GEMINI_API_KEY 필요)
```

## 알려진 한계

- 가족 비밀번호는 8자 이상. 로그인은 로그아웃을 누르기 전까지 유지(세션 만료 없음, 다른 기기에서 비밀번호를 바꾸면 그 기기들만 다시 로그인). 로그인 잠금(15분에 10번)은 가족 아이디 기준이라, 아이디를 아는 사람이 일부러 틀려 잠글 수 있어요
- 같은 IP에서 한 시간에 가족을 40개 넘게 만들 수 없고, 무료 AI는 모든 가족 합계 하루 글 5000·사진 500회까지예요(무료 키 보호)
- AI 채점(‘내 답도 맞는 것 같아요’)은 학생 답을 AI에 그대로 보내므로, 답에 지시문을 적으면 자기 퀴즈를 통과시킬 수 있어요(그 가족 기록에만 영향)
- 발음 인식은 브라우저 기능이라 기기마다 정확도가 다름. 인식이 안 되는 곳은 녹음 비교(스스로 판단)로 대신함. 점수는 '알아들은 말'과의 유사도라 음소 단위 채점은 아님
- 마이크 고르기는 크롬 최신판만 인식에 반영되고, 다른 브라우저는 기기 기본 마이크를 씀
- 알림 실제 도착은 기기에서 확인 필요(자동 점검은 발송 경로·실패 처리까지만). 아이폰은 iOS 16.4 이상·홈 화면 앱에서만
- 사파리로 넘기기(x-safari- 주소)는 iOS 17 이상에서 동작, 그보다 낮으면 안내대로 사파리에서 직접 열기
- 가족 안에서는 서로 믿는 구조라, 비밀번호를 걸지 않은 구성원은 다른 가족이 대신 문제를 풀거나 시험 계획을 고칠 수 있음(숫자 비밀번호를 걸면 막힘)
- 무료 AI(Gemini)는 붐비는 시간에 느리거나 잠깐 실패할 수 있음(재시도·가벼운 모델로 대체)
- 기기 글자인식(대체용)은 AI보다 정확도가 낮고 처음 한 번 언어 데이터(약 10MB)를 내려받음
- 예문 "관련 이미지"는 현재 장면 이모지로 표시(실사 이미지 생성은 비용 때문에 다음 단계)
- 로그인은 같은 아이디로 15분에 10번 틀리면 잠김(그 이상의 보안 장치는 없음)
- 단어 번호는 지운 번호를 다시 쓰지 않음(빈 번호가 생길 수 있음)
- SNS 사용 시 학습 잠금은 웹앱으로는 불가능해 제외(추후 앱 포장 시)
