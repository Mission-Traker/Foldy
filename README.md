# 폴디 Foldy — 접어서 외우는 가족 영어 단어장

**라이브: https://foldy-lake.vercel.app** (GitHub main에 올리면 Vercel이 자동 배포)

초등 1학년부터 성인까지, 가족이 한 아이디로 함께 쓰는 영어 단어장 웹앱입니다.
교재 사진을 찍으면 단어가 한꺼번에 들어가고, 수첩처럼 **정답을 가림판으로 가린 세로 목록**에서 여러 단어를 한 번에 외웁니다.
모바일 브라우저에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 기능

**1차**
- 처음 접속하면 소개 슬라이드 8장(아이콘 3개가 하나씩 튀어나오며 주요 기능 소개, 다음·이전·밀기) → 마지막 장 '폴디 시작하기'로 앱 진입. 기기마다 한 번만(localStorage `foldy.introSeen`), 내 정보 '폴디 소개 다시 보기'로 다시 열기
- 가족 아이디+비밀번호 로그인 → 구성원(프로필) 선택. 이메일·전화번호는 받지 않음
- 구성원별 숫자 비밀번호(4~6자리, 선택): 걸면 다른 가족은 내 단어장을 못 고치고 **학습현황만** 볼 수 있음(DB 보안정책으로 강제). 프로필을 바꾸면 다시 잠김
- 상단 프로필 아이콘 → 이름·캐릭터·레벨·비밀번호 수정, 가족 학습현황(○△✕ 막대·연속일·오늘 정답)
- 단어 추가
  - 📷 사진: 여러 장 한 번에, JPG·PNG·WEBP·아이폰 HEIC(확장자가 틀린 HEIC 포함) 모두 → 긴 변 2000px로 줄여 AI가 읽음 → 미리보기에서 고친 뒤 저장. 기다리는 동안 캐릭터 대기화면(진행률·팁·톡 누르면 점프)
  - AI를 못 쓰면(키·크레딧·서버 오류) 기기 안 무료 글자인식(Tesseract, 영어+한국어)으로 자동 대체. 빈 파일·iCloud 미다운로드 등 못 읽은 사진은 이유와 함께 표시
  - ✍️ 직접 적기: 영어나 한글 몇 글자만 쳐도 사전 9,121단어에서 바로 찾아 탭하면 담김(사전에 없으면 AI가 자동으로 찾아 'AI' 표시로 보여주고 결과는 공유 캐시에 저장) + 여러 개 한 번에 적기(`apple 사과`, 뜻이 비면 사전으로 채움)
- 접이식 단어장: 뜻 가리기·영어 가리기·모두 보기, 가림판 탭하면 열림, 영어 탭하면 발음 재생
- 단어장 한 칸: 번호·영어 철자·🔊·'탭해서 보기' 가림판, 아래에 3단계 학습 아이콘(뜻·철자·발음 — 통과한 것은 주황·초록·코랄 색 + ✓)과 추가 날짜
- 번호/날짜/ABC 정렬(↑↓), 미학습 / △ 학습 중 / ○ 완료 필터, 상단 '○를 기다리는 단어 N개 → 지금 끝내기'
- 단어 바로 뒤 🔊 발음 듣기, ⋯ 메뉴 → ✏️ 고치기 / 🗑 삭제(확인 후 삭제)
- 긴 단어는 글자 크기를 줄이고 줄바꿈해서 모바일에서도 잘리지 않음
- 퀴즈 첫 문제부터 발음 자동 재생(영어→뜻·발음 퀴즈), 아이폰 소리 제한은 첫 터치 때 잠금 해제
- 퀴즈 3종(10문제씩, 못 맞힌 단어 먼저)
  - 퀴즈마다 이미 통과한 단어는 건너뛰고 남은 단어만 출제. 끝나면 '모르는 단어 N개 한 번 더'(새로고침 없이 남은 것만), 모두 맞히면 ✓ 통과 안내
  - 영어 → 뜻: 어미·띄어쓰기·여러 뜻 중 하나·오타 1자 허용 + AI 허용답안 + "내 답도 맞아요"(AI 재채점)
  - 뜻 → 영어: 철자 정확히(대소문자·관사 무시)
  - 발음: 음성 인식 결과를 철자·소리 유사도로 비교해 **정석 발음 대비 70% 이상이면 통과**(정확도 % 표시, r/l·v/f 혼동 허용). '🎧 더 정확한 발음 들어보기' → 보통/천천히 듣기, 발음기호, 강세 음절, 한글 흉내, 입 모양 요령, 내 발음 조언
  - 마이크 선택: 기기 마이크 목록·소리 크기 테스트(내 정보, 발음 퀴즈 안). 크롬 최신판은 고른 마이크로 인식, 그 외는 기기 기본 마이크
- 틀리면 "📌 오답노트로 보내기" → 오답노트에서 틀린 방식별로 다시 연습, 맞히면 자동으로 빠짐
- **○ 판정: 세 가지 퀴즈를 모두 맞혀야 ○**
- 학습 화면: 모두 맞힌 퀴즈는 초록 ✓, 진행 막대 / 🎯 ○ 만들기 도전(✕·△ 단어의 못 맞힌 퀴즈만 모아서)
- 효과음(타자·정답 차임·오답·팡파르, 끄기 가능)과 정답·오답 캐릭터 애니메이션·색종이
- 🛠 앱 수정요청(내 정보): 유형(버그·화면·불편·기능·기타)·화면 칩 + 내용(2,000자) → 우리 가족이 보낸 요청 목록에서 상태(접수됨·고치는 중·의견 보류·고쳤어요)와 답장 확인, 새 답장은 '새 소식'으로 표시. 멘토링대학교 수정요청 구조를 그대로 가져옴
- 수정요청함(`/#/admin`, 관리자 가족만): 상태 필터·신규 배지, 확인→수정진행·의견보류·수정완료, 빠른 답장·답장 고치기, 삭제. 관리자 가족은 DB `foldy_admins`(현재 bang9family)

**2차**
- 레벨 6단계 + 레벨 진단(레벨별 5단어 중 4개 이상 알면 다음 단계)
  - 기준: 2022 개정 영어과 교육과정 [별표 3] 기본 어휘 3,000개
  - 초등 권장(*) 800개 → 초1-2(그림으로 떠오르는 기본 단어 211개) / 초3-4 / 초5-6, 중·고 공통(**) 1,200개 → 중등, 나머지 → 고등, 성인은 AI 추천
- 오늘의 추천 단어 5개: 처음엔 레벨 목록에서 날짜별로 고정 선택, 내 단어가 20개 이상이면 내 단어와 연관된 단어를 AI가 추천
- 확장 학습: ○ 단어 → 유의어·반의어 퀴즈(영어·한글·발음 듣기/연습) → 둘 다 맞히면 예문(영어+한글+문장 읽기+장면 이모지)이 단어장에 열림
- 복습: ○ 단어를 1·3·7·30·60일 뒤 재출제, 틀리면 △로 내려감
- 연속 학습일(🔥), 하루 목표 기본 5개(홈 '✎ 목표 바꾸기'·내 정보에서 1~50개로 조절) — 목표 수만큼 오늘의 추천 단어가 나옴

## 기술 구성

| 부분 | 내용 |
|---|---|
| 화면 | React 18 + Vite 5 + Tailwind 3, HashRouter, 390px 모바일 우선 |
| 데이터 | Supabase `modu-publish` 프로젝트의 `foldy_` 표 6개 (글로자 표와 분리) |
| 수정요청 | `foldy_feedback`(상태·답장은 관리자만 바꿈, 가족·상태는 서버 트리거가 정함) · `foldy_admins` · RPC `foldy_is_admin`·`foldy_feedback_seen` |
| 로그인 | `foldy_signup`/`foldy_login` 함수 → 세션 토큰을 `x-foldy-token` 헤더로 보내고, 모든 표는 RLS로 가족 단위 격리 |
| AI | Vercel 서버 함수 `api/*.js`에서만 Claude API 호출(키는 브라우저에 노출 안 됨). 같은 단어의 AI 결과는 `foldy_cache`에 저장해 재사용 |
| 발음 | 기본 어휘 3,000개는 오픈소스 Kokoro 음성(af_heart)으로 미리 만든 아나운서 음성 파일(`public/audio/*.mp3`), 그 밖은 기기에서 가장 좋은 영어 음성 자동 선택. 인식은 브라우저 음성 인식 — 모두 무료 |
| 사전 | `src/data/dict.json` 9,121단어 영-한 뜻(기본 어휘 + 생활·교과 어휘, 자동완성·추천 단어 뜻). 없으면 `api/lookup` AI 검색 |
| 배포 | GitHub `Mission-Traker/Foldy` → Vercel 자동 배포 |

### 데이터 저장 위치 (`supabase/001_init.sql`, 적용 완료)
- `foldy_families` 가족(아이디, 비밀번호 해시, 이름) · `foldy_sessions` 로그인 토큰(180일)
- `foldy_members` 구성원(이름, 캐릭터, 레벨, 하루 목표, 연속 학습일)
- `foldy_words` 단어(번호, 영어, 뜻, 허용답안, 퀴즈별 정답 여부, 오답노트 모드, 유의어·반의어·예문, 복습 단계·날짜)
- `foldy_daily` 하루 기록(맞힌 수, 오늘의 추천) · `foldy_cache` 단어별 AI 결과 공유 캐시

## 환경 변수 (Vercel)

| 이름 | 필수 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | AI 기능에 필요 | 없으면 사진 읽기·유의어/반의어·예문·연관 추천·AI 재채점이 꺼지고 나머지는 정상 동작 |
| `FOLDY_MODEL_VISION` | 선택 | 사진 읽기 모델(기본 `claude-sonnet-5-5`) |
| `FOLDY_MODEL_TEXT` | 선택 | 글자 작업의 Claude 모델(기본 `claude-haiku-5-5`) |
| `FREE_LLM_BASE_URL` | 선택 | 무료 LLM의 OpenAI 호환 주소(예: `https://…/v1`). 넣으면 유의어·예문·채점·추천을 무료 LLM이 먼저 처리하고, 실패하거나 형식이 깨지면 Claude가 대신함 |
| `FREE_LLM_API_KEY` | 선택 | 위 주소의 API 키 |
| `FREE_LLM_MODEL` | 선택 | 모델 이름(기본 `auto`) |

사진 읽기는 이미지 인식이 필요해 항상 Claude를 씁니다.
※ 맥에서 돌리는 FreeLLMAPI(`localhost:3001`)는 Vercel 서버가 접근할 수 없습니다. 인터넷에서 닿는 주소(배포한 FreeLLMAPI, OpenRouter·Groq 등 무료 키)를 넣어야 합니다.

Supabase 주소·공개 키는 코드에 기본값이 들어 있습니다(공개용 키, RLS로 보호).

## 로컬 실행

```bash
npm install
npm run dev          # 화면만 (AI 경로 /api 는 동작 안 함)
npx vercel dev       # AI 경로까지 (Vercel CLI 로그인 + ANTHROPIC_API_KEY 필요)
```

## 테스트

```bash
npm test                                   # 단위 테스트 97개(채점·상태·복습·정렬·레벨·입력검증·AI 경로 보호)
npm run build && npx vite preview --port 4173 &
BASE=http://localhost:4173 node tests/e2e.mjs   # 브라우저 자동 점검 52개(390px)
BASE=http://localhost:4173 node tests/e2e-retry.mjs  # '한 번 더' 검수 7개(느린 인터넷 흉내)
BASE=http://localhost:4173 node tests/e2e-intro.mjs   # 소개 슬라이드 14개
PHASE=a FID=e2e_fbxx node tests/e2e-feedback.mjs   # 수정요청 접수 10개 → SQL로 그 가족을 foldy_admins에 넣고
PHASE=b FID=e2e_fbxx node tests/e2e-feedback.mjs   # 관리자 처리·답장 11개 (끝나면 foldy_admins에서 다시 빼기)
```
e2e는 실제 DB에 `e2e_`로 시작하는 테스트 가족을 만듭니다.

## 알려진 한계
- 발음 인식은 브라우저 기능이라 기기마다 정확도가 다름. 아이폰은 사파리에서, 홈 화면 앱 모드에서는 동작하지 않을 수 있음. 점수는 '알아들은 말'과의 유사도라 음소 단위 채점은 아님
- 마이크 고르기는 크롬 최신판만 인식에 반영되고, 다른 브라우저는 기기 기본 마이크를 씀
- 기기 글자인식(대체용)은 AI보다 정확도가 낮고 처음 한 번 언어 데이터(약 10MB)를 내려받음
- 예문 "관련 이미지"는 현재 장면 이모지로 표시(실사 이미지 생성은 비용 때문에 다음 단계)
- 로그인은 같은 아이디로 15분에 10번 틀리면 잠김(그 이상의 보안 장치는 없음)
- 단어 번호는 지운 번호를 다시 쓰지 않음(빈 번호가 생길 수 있음)
- SNS 사용 시 학습 잠금은 웹앱으로는 불가능해 제외(추후 앱 포장 시)
